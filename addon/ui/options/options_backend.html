Backend Application

The backend application extends Scrapyard beyond WebExtensions limits, providing filesystem access and other native features. On Windows it can be installed automatically; other platforms use the CLI-based installer (requires Python 3.10+).

Install

  • Automated Windows installer
  • CLI-based installer (macOS, Linux, Windows)

Restart your browser after installing. Close it completely before updating.

Configuration

The backend can also run as a shared server - install with the --server option and select Server as the content location in settings. Access via LAN or Tailscale.
