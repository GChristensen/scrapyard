# Scrapyard

[Scrapyard](https://gchristensen.github.io/scrapyard/) is a Scrapbook alternative for Firefox Quantum.

ScrapBook was a brilliant extension. I haven't found a usable alternative, so I tried to create
a bookmarking addon that might be as usable as the legacy ScrapBook itself.

### Credits

* vclfence's [ScrapBee](https://github.com/vctfence/scrapbee) was used as a starting point,
although currently no code from ScrapBee is left in Scrapyard.
* A good portion of knowledge from the open-source [SavePageWe](https://addons.mozilla.org/en-US/firefox/addon/save-page-we/) addon
was used to create Scrapyard page capture engine.


### JSON Scrapbook File Format

The JSON Scrapbook archive format used by Scrapyard is documented
[here](https://github.com/GChristensen/scrapyard/wiki/JSON-Scrapbook-File-Format).
